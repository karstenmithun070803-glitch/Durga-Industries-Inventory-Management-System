# HSN Codes

## What is an HSN Code?

HSN (Harmonised System of Nomenclature) is a government-assigned 8-digit code that classifies every type of goods under India's GST system. It must appear on GST invoices for each material line item.

## Who assigns it?

The government assigns codes — you look them up, you don't invent them. Sources:
- Your CA (Chartered Accountant)
- GST portal: [https://www.gst.gov.in](https://www.gst.gov.in) → HSN/SAC search
- CBIC HSN master list

## Is it required to start using the software?

No. The field is optional in the Material Master. The system works fully without HSN codes. Fill them gradually as materials are invoiced to customers (required on customer invoices above ₹50L turnover threshold).

## Common examples for a bus body manufacturer

| Material | HSN Code |
|----------|----------|
| MS Angle Iron | 72162100 |
| MS Flat | 72131000 |
| MS Sheet | 72082700 |
| MS Pipe / Tube | 73063090 |
| Paint (synthetic) | 32091010 |
| Glass | 70072900 |
| Bolt / Nut | 73181500 |
| Wire | 72170010 |

> These are indicative. Confirm exact codes with your CA before use on invoices.

## Where it appears in the software

- **Material Master** → HSN Code column (8 characters, manually entered)
- **Sales Invoice** (Phase 5) → printed on each line item
